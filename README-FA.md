# یار کشاورز — Final Clean Offline

این نسخه یک ساختار تمیز و Offline-first از «یار کشاورز» است.

## اجرای برنامه
- نقطه ورود: `index.html`
- داده‌های مزرعه در LocalStorage مرورگر ذخیره می‌شوند.
- دستیار کشاورزیار در `offline/offline-ai.js` و بانک دانش در `offline/agriculture-db.js` قرار دارد.
- Service Worker در `sw.js` پوسته اصلی برنامه را برای استفاده آفلاین cache می‌کند.
- `worker/index.js` برای اتصال آنلاین آینده حفظ شده است.

## نکته مهم آفلاین
نقشه‌های آنلاین Leaflet/OSM در نبود اینترنت قابل دریافت نیستند؛ بخش‌های اندازه‌گیری و داده‌های محلی برنامه تا حد امکان مستقل از اینترنت هستند. تحلیل واقعی عکس با مدل هوش مصنوعی نیازمند اتصال آنلاین است.
