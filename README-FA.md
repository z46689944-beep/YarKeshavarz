# یار کشاورز — V3 CLEAN

نسخه تمیز و یکپارچه برنامه مدیریت مزرعه.

## بخش‌های اصلی
- صفحه خانه و داشبورد
- مدیریت زمین‌ها و پرونده هر زمین
- اندازه‌گیری زمین با نقشه و پیمایش GPS
- آب‌وهوا برای زمین و موقعیت فعلی
- هزینه، درآمد و گزارش
- انبار
- عکس و اطلاعات زمین
- کشاورزیار
- اخبار و تبلیغات
- اکانت و پشتیبان‌گیری
