# V28 — اتصال تحلیل مزرعه به موتور برنامه‌ریزی عمومی

این نسخه یک باگ مهم V27 را اصلاح می‌کند: دکمه «تحلیل مزرعه / تحلیل وضعیت فعلی» در `index.html` قبلاً مسیر قدیمی `yarAnalysisText()` را اجرا می‌کرد و در نتیجه `offline/farm-planner.js` اصلاً اجرا نمی‌شد.

در V28 این دکمه از همان pipeline گفت‌وگو استفاده می‌کند و در حالت آفلاین مستقیماً `offline-ai.js` و موتور برنامه‌ریزی عمومی را صدا می‌زند؛ در حالت آنلاین نیز مسیر آنلاین را حفظ می‌کند و در صورت خطا به آفلاین fallback می‌کند.

همچنین نام cache سرویس‌ورکر از v27 به v28 تغییر کرده تا نسخه قدیمی `index.html` از cache باقی نماند.
