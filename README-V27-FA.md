# کشاورزیار V27 — موتور برنامه‌ریزی عمومی مزرعه

این نسخه مشکل «گیر کردن روی یک محصول» را در سطح معماری حل می‌کند.

### چه چیزی عوض شده؟
- `offline/farm-planner.js` یک لایه مستقل و داده‌محور برای برنامه‌ریزی عددی است.
- نام‌های placeholder مثل `هیچی`، `ندارد` و `ثبت نشده` دیگر محصول واقعی محسوب نمی‌شوند.
- بذر، آبیاری، عملکرد، هزینه و درآمد فقط بر اساس مساحت همان زمین محاسبه می‌شوند.
- اگر برای محصولی پروفایل عددی معتبر در رجیستری نباشد، عدد ساختگی تولید نمی‌شود و پروفایل کیفی ادامه پیدا می‌کند.
- تطبیق موجودی فقط وقتی انجام می‌شود که محصول واقعی مشخص باشد؛ بنابراین «بذر موسیر» دیگر به زمین با محصول «هیچی» نسبت داده نمی‌شود.
- `sw.js` نسخه کش را به V27 برده و `farm-planner.js` را برای حالت آفلاین در هسته کش قرار داده است.

### فایل‌های تغییرکرده
- `offline/farm-planner.js` (جدید)
- `offline/offline-ai.js`
- `sw.js`

### نکته مهم
این بسته UI و کارت‌های V19 را دست نمی‌زند. برای حفظ نسخه پایدار، فقط همین فایل‌ها را روی مخزن فعلی جایگزین/اضافه کن.
